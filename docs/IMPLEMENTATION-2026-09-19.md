# 本轮修复与验收

本轮按 `AI-Resonance-review-2026-09-19.md` 的审查意见实现，保留静态发布架构与透明排名规则。

## 故障修复

- 冷启动时提前注册 AI / 搜索设置元数据，导入配置时执行端点检查、密钥绑定清理和导出脱敏。
- 定稿按来源独立完成；成功来源不再使失败来源永久停止补采。
- Hugging Face 与 arXiv 各自保留发布时间、公告时间、提交时间，修复重复记录合并后的归期。
- 已定稿的官方公告不再被未来互动指标反向改写。
- 首次只有实时数据时仍生成可访问的首页和 manifest；展示冷启动覆盖信息。
- 日期请求失败清除旧数据显示；详情历史状态随条目重置；临时选择 Key 后重试使用新选择。
- 中文输入法组合输入时 Enter 不会误触搜索结果。
- 部分收件人投递失败保留状态，仅重试失败对象；测试邮件须有真实发送确认步骤。
- SMTP 自定义密码保留空格；周报增加实际覆盖区间预览，新配置默认为周二。
- 本地服务对格式错误 URL 返回 400；Vite dev / preview 对不存在的 API 文件返回 404。
- 历史日刊主动刷新绕过缓存，首次访问遇到 manifest 晚到也能正确选择实时版。

## 阅读与界面

- 阅读库：收藏、稍后读、已读、未读筛选、双语最小内容快照、刷新持久化及数量上限。
- 兴趣规则：关键词、公司、GitHub 项目关注和静音，带常用兴趣预设。
- 事件概览：依据已有跨来源关联聚合，区分新增、更新和已看；忽略热度变化，个人筛选不制造虚假更新。
- 统一搜索：实时与归档合并、实体去重、来源标记和部分失败重试。
- 状态页：实际采集时间、发布时间、覆盖缺口、逐源定稿、邮件实际投递结果。
- 更紧凑的首页、手机当前榜单分类计数、简化卡片操作、默认折叠技术日志和分层配置说明。
- 可中断页面过渡、筛选与列表位移动画、分类及标签滑块、抽屉退出及拖动回弹；兼容系统和应用的减少动态效果设置。
