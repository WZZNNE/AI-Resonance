# 入门推荐 / Beginner picks

产品更新与选材说明集中在 [中文 README](../README.zh-CN.md#更新--2026-09-21) 和 [English README](../README.md#update--2026-09-21)。阅读页保留简短介绍、来源和筛选，不重复展示规则说明。

## 数据与入口

- 交互页：`#/learn`；无需 JavaScript 的阅读页：`learn/`。
- 静态 API：`api/v1/beginner.json`，独立于原有五类日报榜单。
- 初始常驻目录：`packages/pipeline/src/beginner/catalog.ts`；动态启动目录独立维护。它们是经过编辑选择的实用资源，不代表当天发布的内容。
- 持久状态：`data/state/beginner.json`，由 GitHub Actions 的 `data` 分支保存。

每次发布固定输出 100 项、30 常驻和 70 动态，URL 归一化后跨区去重。动态内容允许较早发布的实用资料。候选不足时，历史候选与动态启动库继续参与选取，不产生空位，不凭空编造新资源。

## 常驻与动态

初始 30 项提供稳定入口，但之后的常驻名单由状态保存，不会每次发布恢复到初始目录。先把合格候选按分数正常排序，用没有席位保护时的第 100 名确定当日淘汰线；严格低于它的常驻项才可能被替换。

替补从近 30 天曾进入动态区的内容中产生，以入选日综合评分的平均值排序，再依次比较当前分数、最近入选日、稳定 ID；当前分和月均分都必须高于被替换项。只入选一天也可参与，不补造缺失日期成绩。日内多次采集只保留同一天一份成绩，不额外加权。晋升、降为动态和离榜分别处理；只是在两个区域间移动不重置首次入榜时间。

四项学习分为基础性、清晰度、实践价值和来源，各 0–5 分，合计乘 5。编辑资料逐项评估，自动候选按源内容的可观察信号评分；这是透明的推荐规则，不是学习效果或论文影响力测量。

## 日期与兼容

原始发布时间、项目更新时间、首次采集、首次入榜和链接核查日期彼此独立。未知时间不编造；首次采集旧资料不会被描述为“最新发布”。初始资源不显示 NEW，之后真正首次入榜与回归分别显示 `NEW` / `BACK` 七天；浏览器离线读取旧文件时也会检查标签到期。

数据生成器随 `publishAll` 运行。默认工作流每三小时采集，并在日切窗口额外运行；浏览器前台每五分钟、恢复前台或恢复网络时重新请求。展示的更新时间来自实际发布与输入采集记录，不保证秒级实时。

旧版本状态升级时保留 URL 对应的首次入榜和回归历史，新增常驻与近月动态记录。筛选规则升级会重新检查候选池。损坏状态导致发布失败并保留原文件，不用清空历史掩盖问题。

## 维护与验证

更新资源时核实官方入口、用途、先修要求和评分，避免多个条目只是同一任务的重复入口。源码、商业工具、文档各自的可用范围以原始来源为准；链接可访问不等于完整功能经过实测。自动发现无中文解读时显示原文。

回归覆盖固定 100/30/70、跨区去重、候选排序、常驻淘汰与近月替补、同日重复发布、历史迁移、NEW/BACK、筛选和静态分享。编辑评估与自动规则不能保证外部资源一直有效，维护者仍需随产品变化调整目录。
